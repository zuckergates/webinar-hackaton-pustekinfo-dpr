# Hasil pengujian lokal

Jalankan `Test` lalu `Attacks` secara berurutan. Laporan baru, log, dan dump di folder ini diabaikan Git. Periksa timestamp dan run ID sebelum memakai hasilnya.

Contoh laporan paket asal disimpan terpisah di [contoh-hasil](../contoh-hasil/README.md).

PASS pada baseline berarti kelemahan yang sengaja disiapkan berhasil direproduksi.
